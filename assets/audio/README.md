## Usage Rule

2026-05-30時点では、Codex Arcadeは非商用の実験プロジェクトとして運用している。

Sunoで作成した音源は、現時点では以下の範囲で扱う。

```txt
v0.1 non-commercial experiment BGM
```

広告、課金、スポンサー、販売、商用告知、収益化を始める場合は、音源の利用条件を再確認する。

## Do Not Commit

以下は保存しない。

- Sunoアカウント画面のスクリーンショット
- 個人アカウント情報
- 支払い情報
- プラン画面の個人情報

保存するのは、公開してよい音源ファイルと制作メモのみ。
