# Changelog

## 0.1.2 - 2026-05-30

- Added Neon Core Run as looped gameplay BGM.
- Expanded the sound toggle to control both BGM and minimal SFX.
- Added BGM fade-out on clear and game over.
- Made sound enabled by default so Start Run begins the BGM unless muted.

- Moved the title screen arcade return link into a quieter corner position.
- Added result details for survival time and local best score.
- Added an optional minimal sound-effects toggle.

- Added Codex Arcade launch flavor for `?from=arcade&credit=1`.
