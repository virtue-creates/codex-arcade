# Arcade Experience Brief

This brief is for Marketing and Creative brainstorming.

## Goal

Rework Codex Arcade's public-facing MVP shell so it feels more like an online arcade and less like a generic project dashboard.

## Important Distinction

Internal project identity:

```txt
AI-agent-operated arcade studio
```

Public first impression:

```txt
An online arcade where the player chooses a cabinet, inserts a credit, and starts one play.
```

The AI-agent company story is valuable, but it should not overpower the first arcade screen.

## Current Problem

The first MVP shell works structurally, but it does not yet create arcade excitement.

Observed issues:

- Too much project/dashboard feeling.
- Too little cabinet/arcade feeling.
- English copy makes the project feel less personal.
- Phase/Sprint display feels internal and should not be public-facing.
- Cabinet presentation feels like cards, not cabinets.
- Credit display feels decorative rather than experiential.

## Desired Brainstorming Direction

Explore how to create:

- A stronger first impression.
- A cabinet selection feeling.
- A clearer one-credit / one-play flow.
- Japanese-first explanatory copy.
- Arcade UI terms where useful.
- Coming soon cabinets that feel like covered or inactive machines, not generic disabled cards.

## Inspirations

Use these as emotional references, not strict visual requirements:

- Japanese game centers
- A row of cabinets
- Sitting down to play
- 100 yen / one credit
- A cabinet waking up
- Attract mode
- Insert coin prompt
- Neon signs
- Game selection in a physical-feeling space

Avoid making the direction a literal copy of any real arcade, brand, or specific game cabinet.

## Output Needed

Marketing and Creative should propose options, not final implementation.

Good outputs include:

- Public positioning options
- Top screen copy options
- Cabinet selection concepts
- Credit / INSERT COIN experience ideas
- Coming soon cabinet treatment
- Visual tone options
- Risks or tradeoffs
