## Recommended First Post

最初は、Marketing Departmentレビュー後のX/SNS Copyを使う。

理由:

- 「人間ディレクターとCodex agentsで作っている」ことが伝わる。
- 「オンラインゲーセン」として何を開くのか分かる。
- 「店長にメモ」で改善ループに参加できることが伝わる。
- 完成版ではなくv0.1として出している温度感が合う。
- 改善の約束が強すぎない。
