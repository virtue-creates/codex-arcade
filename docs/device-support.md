# Device Support

Codex Arcade should be readable on desktop, tablet, and mobile.

Individual games may support fewer devices.

## Labels

```txt
desktop: PC and laptop browsers
tablet: iPad and Android tablets
mobile: iPhone and Android phones
```

## Input Labels

```txt
keyboard
mouse
touch
gamepad
```

## Orientation Labels

```txt
landscape
portrait
flexible
```

## Recommended Phase 1 Policy

- Parent arcade site: desktop, tablet, and mobile friendly.
- Games: desktop first.
- Tablet support: recommended when practical.
- Mobile support: game-by-game decision.

Game cards should clearly show supported devices and input methods.

## PWA Direction

Codex Arcade may later become a PWA.

A PWA is a web app that can be added to a phone home screen and launched like an app. This is a good future step before considering App Store or Google Play releases.
