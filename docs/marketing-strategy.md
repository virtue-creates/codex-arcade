# Marketing Strategy

Marketing for Codex Arcade should support the larger goal: experiencing an AI-agent-operated game studio.

## Marketing Role

Marketing is responsible for:

- Explaining what Codex Arcade is.
- Helping people understand why it is interesting.
- Creating entry paths to the site.
- Turning releases into clear announcements.
- Learning which games and pages attract attention.
- Suggesting improvements to the arcade and game pipeline.

## Positioning

Working positioning:

```txt
Codex Arcade is an AI-agent-operated online arcade experiment where a human director and Codex departments plan, build, QA, publish, market, analyze, and improve small web games.
```

Short version:

```txt
An online arcade built and operated with Codex agents.
```

## Phase 1 Marketing

Before public analytics:

- Define audience.
- Write site copy.
- Write game card copy.
- Keep production notes.
- Prepare release announcement templates.
- Prepare social post drafts.
- Make the GitHub README understandable.
- Make the arcade concept easy to explain.

## Phase 2 Marketing

After the first playable public site:

- Share release notes.
- Share game-specific posts.
- Improve homepage wording.
- Improve game card ordering.
- Add basic SEO metadata.
- Decide whether to add analytics.

## Phase 3 Marketing

After analytics exists:

- Review traffic.
- Review game clicks.
- Review device mix.
- Review entry pages.
- Suggest homepage changes.
- Suggest next game concepts from observed interest.

## Content Types

- Release announcement
- Game launch post
- Weekly development log
- Behind-the-scenes studio note
- "How this was made with Codex" post
- Game-specific teaser copy
- Screenshot caption

## Marketing Guardrails

- Do not imply real-money rewards.
- Do not call free credits money, purchases, deposits, or tokens.
- Do not overpromise automation.
- Do not use unapproved brand names or protected characters.
- Keep privacy claims accurate.
- Keep the human director visible in final approval.
