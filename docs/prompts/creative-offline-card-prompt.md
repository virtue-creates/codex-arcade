## Marketing Department Request

Codex Arcade v0.1の初期テスター向けに、手渡し用の名刺/カードデザインを提案してください。

目的:

身近な人にリアルでカードを渡し、Codex Arcadeへアクセスしてもらい、Cabinet 01: Neon Core Survivorをプレイし、店長メモを残してもらう導線を作る。

背景:

Codex Arcadeは、人間ディレクターとCodex agentsで運営しているオンラインゲーセンです。
v0.1は完成版ではなく、「遊ばれながら改造されるオンラインゲーセン」として公開しています。

トーン:

- 普通のビジネス名刺ではない
- ゲーセンの招待券/筐体カード/入場券のような雰囲気
- 良い意味でのふざけ・ノリがある
- ただし情報は迷わない
- 「変な筐体です」と説明しすぎず、何これ？と思える余白を残す
- ノリはふざける。運用はちゃんとする。

入れたい要素:

- Codex Arcade
- v0.1
- Cabinet 01: Neon Core Survivor
- QRコード
- URL
- 店長メモへの誘導
- 1 CREDIT = 1 PLAY などの無料演出
- CREDITSは購入/換金/報酬ではないことが誤解されない表現

出してほしいもの:

- 表面/裏面の構成案
- コピー案
- 視覚トーン案
- 印刷サイズ案
- QRコード配置案
- 避けるべき表現

## 使用URL

QRコードには以下のURLを使います。

```txt
https://virtue-creates.github.io/codex-arcade/?utm_source=offline_card&utm_medium=physical&utm_campaign=v0_1_launch&utm_content=namecard
```

## 目的

身近な初期テスターに、URLをただ送るのではなく、リアルに小さなカードを渡して、

1. Codex Arcadeにアクセスする
2. Cabinet 01: Neon Core Survivor をプレイする
3. 店長メモを残す

という流れを作りたいです。

## Creativeに考えてほしいこと

普通のビジネス名刺ではなく、ゲーセンの招待券、筐体カード、怪しい入場券のような雰囲気にしたいです。

ただし、情報は分かりやすくしてください。

大事な方針:

```txt
ノリはふざける。
運用はちゃんとする。
```

## 必須要件

- 表面は世界観重視。
- 裏面は行動導線重視。
- QRコードでCodex Arcadeへ誘導する。
- 店長メモまで誘導する。
- CREDITSは無料演出であり、購入、換金、報酬ではないと分かるようにする。
- 「丁寧な営業」ではなく、良い意味でのふざけ、ノリ、ゲーセン感を出す。
- プレイヤーが「何これ？」と思ってアクセスしたくなる余白を残す。

## 避けたいこと

- 普通の会社名刺に見える。
- 情報が多すぎる。
- QRコードが小さすぎる。
- CREDITSが金銭価値に見える。
- 実決済、暗号資産、ウォレットを連想させる。
- 「必ず改善します」と約束する。
- 最初から「ネタ」「クソゲー」と説明する。
