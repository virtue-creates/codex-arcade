# PR Tone Policy

Codex Arcadeの公開、告知、店長メモ、改造ログ、COMING SOON表示に共通するPR/運営トーン方針。

このドキュメントは、Marketing Departmentが提示した方針を本部docsに正式反映したもの。

## Core Policy

Codex Arcadeでは、丁寧なサービス説明よりも、良い意味でのふざけ、ノリ、企画に乗りたくなる空気を重視する。

ただし、ただ雑にふざけるのではない。

大事にするバランス:

- ノリはふざける。
- 運用はちゃんとする。
- プレイヤーを馬鹿にしない。
- 店長メモや感想を雑に扱わない。
- 安全性、プライバシー、クレジット表現は真面目に守る。

Codex ArcadeのPRは、「AIプロダクトの説明」よりも、オンラインゲーセン運営そのものを遊びにする方向で考える。

## Leave Room For "What Is This?"

Codex Arcadeでは、「変な筐体です」「ネタゲーです」と先に説明しすぎない。

プレイヤーが自分で「何これ？」と思える余白を残す。

避けたいこと:

- 変なものを、運営側が先に「変です」と言い切る。
- ネタとして消費する前提で説明する。
- 筐体の評価や意味をプレイヤーより先に決めてしまう。

やりたいこと:

- 店内掲示のように、真顔で少しおかしなことを言う。
- 何かが奥で動いている気配を置く。
- 変さを説明するより、変なことが起きていそうな状況を作る。

## Storefront Tone

初回告知やSNSでは、「公開しました」だけでなく、少しゲーセン運営のノリに寄せる。

推奨トーン:

```txt
Codex Arcade v0.1、開けました。

人間ディレクターとCodex agentsで、オンラインゲーセンやってます。
まずは看板筐体「Neon Core Survivor」が稼働中。

遊んだら店長メモを置いてってください。
メモは次の改造の参考にします。
```

ポイント:

- 完成版感を出しすぎない。
- ただし、雑な未完成アピールにしない。
- 店長メモは問い合わせフォームではなく、店に置いてあるメモ帳のように扱う。
- 改善を強く約束しすぎない。

## Manager Memo

店長メモは、単なる改善フォームではない。

役割:

- プレイヤーが運営に参加できる入口。
- 「面白かった」だけでなく、「つまんない」「何これ？」も置ける場所。
- Analyticsでは分からない「なぜ止まったか」を拾う場所。
- 撤去、改造、再搬入、COMING SOONのような運営イベントの起点。

推奨表現:

```txt
メモは次の改造の参考にします。
```

避けたい表現:

```txt
いただいた意見は必ず次回アップデートに反映します。
```

すべてのメモを反映する約束はしない。
ただし、メモを運営がちゃんと見て、改善会議や筐体運用の材料にする。

## Removal / Return / Coming Soon

Codex Arcadeでは、反応が微妙だった筐体や、まだゲーム性が弱い筐体も、PR上の資産にできる。

例:

1. Cabinetが稼働する。
2. 店長メモで「つまんない」「よく分からない」「何これ？」が来る。
3. いったん奥へ下げる。
4. COMING SOON / 改造中 表示にする。
5. 後日、少し違う形で再搬入する。

この流れ自体が、「遊ばれながら改造されるオンラインゲーセン」の体験になる。

表示例:

- 店長メモ確認中
- いったん奥へ
- 改造中
- COMING SOON
- 再搬入準備中
- 前とは少し違うらしいです

「撤去された微妙な筐体が、進化して帰ってくる」ような運営イベントは、Codex Arcadeらしい。

ただし、最初から運営側が「クソゲー」「ネタゲー」とレッテル貼りしない。
プレイヤーが感じる余白を残す。

## Coming Soon Philosophy

COMING SOONは、単なる未実装表示ではない。

使い方:

- 新しい筐体が来る気配。
- 奥で調整されている気配。
- 一度下げたものが戻ってくる気配。
- 前とは少し違うものになる気配。

例:

```txt
COMING SOON
奥で調整中
```

```txt
COMING SOON
前とは少し違うらしいです
```

```txt
COMING SOON
再搬入準備中
```

## Preferred Language

使いたい言葉:

- オンラインゲーセンやってます
- 開けました
- 稼働中
- 1台、点いてます
- 奥で調整中
- いったん下げました
- 改造中
- 再搬入
- 店長メモ確認中
- COMING SOON
- 前とは少し違うらしいです
- メモは次の改造の参考にします

使いすぎ注意 / 避けたい言葉:

- 丁寧に営業しています
- 改善に努めます
- ご意見を品質向上に活用します
- 変な筐体です
- ネタゲーです
- カオスです
- AIが完全自動で運営
- AIが全部作った
- 必ず反映します
- 本当に次のアップデートで改造します

## Guardrails

ノリは大事だが、以下は守る。

- プレイヤーを馬鹿にしない。
- 店長メモを書いた人を晒さない。
- 個人情報を引用しない。
- 感想を勝手に公開しない。
- AIが完全自動で判断したと誤解させない。
- CREDITSを購入、換金、報酬に見せない。
- 実決済、暗号資産、ウォレット連携に見える表現を避ける。

ふざけるのは、運営の語り口と企画の見せ方。

安全性、プライバシー、プレイヤーへの扱いはちゃんとする。

## Operational Use

この方針は、今後の以下に反映する。

- 告知文
- 店長メモの文言
- COMING SOON表示
- 改造ログ
- 撤去/再搬入の見せ方
- Cabinet 02/03など、要改造筐体の扱い
- v0.1.1以降のMarketing Departmentレビュー

本部は、この方針を実装やdocsに反映する。

Marketing Departmentは、告知文、PRイベント、初期導線、運営トーンの専門判断を持つ。
