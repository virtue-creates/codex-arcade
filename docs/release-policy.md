# Release Policy

## Early Release Target

Use GitHub Pages for the first public version.

Recommended path:

```txt
https://[github-user].github.io/codex-arcade/
```

## Release Flow

1. Create or update files locally.
2. Run basic checks.
3. Review game behavior.
4. Commit changes.
5. Push branch.
6. Open PR if using a team workflow.
7. Human approves merge to `main`.
8. GitHub Pages publishes the site.

## Human Approval Required

Human approval is required before:

- Public release
- Merge to `main`
- Adding external assets or libraries
- Adding wallet, crypto, payment, reward, or ranking-prize features
- Changing credit policy
