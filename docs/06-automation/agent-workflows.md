# Agent Workflows

Codex Arcade may later be operated like an AI agent game studio.

## Possible Agent Roles

## Producer Agent

- Turns rough ideas into scoped game concepts.
- Keeps games small enough for fast production.
- Prepares a planning brief.

## Game Builder Agent

- Implements the game.
- Creates `game.json`.
- Creates game README.
- Keeps the game standalone.

## QA Agent

- Runs the QA checklist.
- Checks device behavior.
- Reports bugs with file references and reproduction steps.

## Thumbnail Agent

- Captures screenshots or generates thumbnails.
- Places images under `assets/thumbnails/`.

## Arcade Integrator Agent

- Updates `games.json`.
- Checks parent arcade display.
- Updates docs and production logs.

## Release Agent

- Checks git status.
- Prepares commit and PR.
- Confirms GitHub Pages release status.

## Human Role

The human acts as studio director:

- Approves concepts.
- Approves public release.
- Decides taste, feel, and world direction.
- Reviews any legal, payment, wallet, or external asset risk.
