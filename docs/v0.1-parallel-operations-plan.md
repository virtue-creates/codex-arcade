# Codex Arcade v0.1 Parallel Operations Plan

Codex Arcade v0.1公開後の同時並行運用計画。

目的は、告知発信とクオリティアップを同時に進めること。

ただし、本部が各専門部署の役割を跨がない。

## Current Position

```txt
v0.1 Public
-> Announcement / Player Memo Cycle
-> v0.1.1 Quality Upgrade
```

公開は完了しているが、完成ではない。

v0.1は「遊ばれながら改造されるオンラインゲーセン」として運用する。

## Main Parallel Tracks

| Track | Owner | Current Work | Output |
|---|---|---|---|
| Announcement | Marketing Department | 初回告知文、UTM、初期導線、告知先 | Marketing-reviewed announcement |
| Parent Arcade Quality | Headquarters + Creative Review | トップ崩れ、ゲーセン感、音/BGM、Cabinet 01導線 | v0.1.1 parent patch plan |
| Cabinet 01 Polish | Cabinet 01 Studio | 看板筐体として普通の人に遊ばせる仕上げ | polish report / patch |
| Cabinet 02 Redesign | Cabinet 02 Studio | 「高スコア予測を押すだけ」から脱出 | gameplay redesign proposal |
| Cabinet 03 Redesign | Cabinet 03 Studio | 1回で終わる玩具感から脱出 | replayability / success clarity proposal |
| Creative Direction | Creative Department | トップ演出、BGM/サウンド方向、筐体感 | creative direction brief |
| QA | QA Department | 公開URL、PC表示、Cabinet 01、店長メモ、GA4/Formspree | QA findings |
| Analytics | Marketing / Analytics | GA4と店長メモでどこを見るか | first report format |
| Policy / Safety | Policy & Safety | 公開表現、クレジット、店長メモ、個人情報 | release safety check |

## Headquarters Responsibilities

本部が担当すること:

- 親Arcadeの実装
- 公開URL管理
- GitHub / GitHub Pages管理
- docs管理
- 各部署への依頼文作成
- 各部署の成果物受領
- 採用/保留/却下の整理
- v0.1.1スコープ整理

本部が担当しないこと:

- 告知文の最終案
- マーケターゲットの最終設計
- BGM/ビジュアル表現の専門判断
- Cabinet 02/03のゲーム性設計
- QAの最終判断を無視した実装

## Immediate Concerns

Human Directorからの現時点の懸念:

- トップページが少し崩れている。
- 音楽がしょぼすぎる。
- Cabinet 02はゲーム性がまだできていない。
- Cabinet 03は動きは面白いが、もう一回遊びたい理由が弱い。
- 告知発信はMarketing Department主導に戻す。

## Recommended Work Order

同時並行で動かすが、採用順は以下。

1. Marketing: 初回告知レビューを完了させる。
2. Creative: トップ/BGM/筐体感の改善方向を出す。
3. QA: 公開URLで現状の崩れ・導線を記録する。
4. Cabinet 01 Studio: 看板筐体の小改善を出す。
5. Cabinet 02 Studio: ゲーム性再設計案を出す。
6. Cabinet 03 Studio: リプレイ性と成功体験の再設計案を出す。
7. Headquarters: 受け取った案をv0.1.1候補として整理する。

## v0.1.1 Candidate Scope

v0.1.1で入りそうな候補:

- トップページの表示崩れ修正。
- BGM/音の改善、または一時的に無音寄りへ調整。
- Cabinet 01のBack to Arcade / 店長メモ導線の確認。
- Cabinet 02/03を公開面ではLabとして維持しつつ、内部で再設計。
- 告知文をMarketing Reviewed版に確定。

v0.1.1に入れない候補:

- Cabinet 02/03を無理に公開プレイ可能にする。
- 新規ゲーム追加。
- 決済/暗号資産/ウォレット。
- 大規模デザイン全面刷新。
- ランキング/ログイン。
