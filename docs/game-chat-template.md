Paste this into each game chat before implementation.

Codex Arcadeの共通ルール:
- 静的HTML/CSS/JSで作る想定
- 1ゲームは games/[game-id]/ に入れる

- PC対応を基本、タブレット/スマホ対応はゲームごとに判断
- README.md と game.json を持つ想定

以下の形式で企画案を出してください。

- input:
