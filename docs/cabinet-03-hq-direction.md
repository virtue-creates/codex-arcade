## HQ Summary

Specimen Night Shiftの世界観は悪くない。

本部と人間QAの判断では、問題は「標本箱」「虫」「ピン」という題材そのものではなく、現MVPで何を操作して何が成功なのかが見た目で伝わっていないこと。

現状は、ピンが進路を曲げる道具として読まれにくく、月明かりの出口も出口ではなく容器のように見えている。

次版では、複雑なルール追加より先に「ピンで曲げる」「光へ逃がす」「成功した」が一目で分かる体験を優先する。

## 改善目的

次版では、初見プレイヤーに以下を伝える。

- プレイヤーは虫ではなくピンを動かす。
- ピンの近くを通ると虫の進路が曲がる。
- 右側の光は容器ではなく出口である。
- 虫が出口へ入ると救出成功である。
- 置き方を変えれば次はもっと救出できそう。

## 必須変更

1. ピンの影響を見える化する

- ピンの周囲に薄い影響範囲を表示する。
- 虫が影響範囲に入った時、進路が曲がったことを光や軌跡で示す。
- ピンの効果は現状より少し強くして、触って分かるようにする。

2. 出口を「月明かりの出口」として読ませる

- 容器やバケツに見える形を避ける。
- 右側の光は、箱の外へ抜ける割れ目、開いた隙間、月光の窓、外への小さな出口として見せる。
- 虫が出口に入った時、外へ抜けた/救出されたことが分かる演出を入れる。

3. 成功演出を強くする

- 虫が出口へ入った瞬間に、短い光、カウント増加、`RESCUED` 表示などを出す。
- `1/3`, `2/3`, `3/3` の進行が分かるようにする。
- 成功した虫は画面から消える、または外へ抜けたように見せる。

4. 最初の30秒の理解を助ける

長い説明文ではなく、画面内の見た目と短い文で伝える。

例:

```txt
ピンを動かして進路を曲げる。
虫を月明かりの出口へ逃がしてください。
```

5. 大人向けに残すか、ゆるい玩具方向に寄せるかを判断する

本部の推奨は、大人向けの「奇妙で美しい誘導パズル」に寄せること。

その場合、次版では以下のどれかを入れる。

- 虫の進路を予測しやすい軌跡表示
- 複数虫を同時に誘導するとスコアが伸びる
- ピン移動回数が少ないほど評価が上がる
- 出口付近で微調整する必要がある配置

## 推奨変更

- ピンをドラッグ可能であることを、カーソルや見た目で分かりやすくする。
- 虫の移動速度を少し落とし、観察してから動かせる時間を作る。
- 60秒は維持してよいが、短く感じる場合は45秒でもよい。
- リザルトに `Rescued`, `Pin Moves`, `Best Route` のような上達要素を追加する。

## 今回やらなくてよいこと

- 複数ステージ
- 図鑑/コレクション
- 複雑な虫の性格
- 物理エンジン
- 本格BGM
- postMessage
- サムネイル
- スマホ最適化
- 実決済、暗号資産、報酬要素

## 次回Studio報告に含めてほしいこと

- ピンの影響をどう見える化したか
- 出口表現をどう変更したか
- 成功演出をどう強めたか
- 大人向け/子ども向けの判断
- 初見30秒で何が伝わる想定か
- 起動確認結果
- まだ不安な点

## 次回QAで本部が見ること

- 初見でピンを動かすゲームだと分かるか。
- ピンで虫の進路が変わったと分かるか。
- 月明かりの出口がゴールとして読めるか。
- 虫が出口へ入った時に成功したと分かるか。
- 大人がもう一回やりたい理由があるか。

## 2026-05-16 Studio Response

Cabinet 03 Studioから、HQ Direction対応版の変更報告を受領した。

Studio reported changes:

- 各ピンの周囲に薄い影響範囲リングを表示。
- 虫がピン影響圏に入ると、短い光跡/曲がりエフェクトを表示。
- 虫の速度を少し落とし、ピンによる曲がりを強化。
- 丸い月/容器っぽい表現をやめ、右端の「月明かりの割れ目」として出口を描画。
- `MOON EXIT` の短いラベルを追加。
- 救出時に `RESCUED 1/3` のような浮遊表示と光のリップルを追加。
- HUDを `MOVES` 表示に変更。
- リザルトに `Pin moves` と `fewer moves, more moonlight` の評価軸を追加。
- タイトル文言を `Drag pins to bend the paths. Guide the specimens through the moonlit crack.` に変更。

Studio target decision:

- 本部推奨どおり、ゆるい玩具方向ではなく「大人向けの奇妙で美しい誘導パズル」に寄せた。
- 難度を急に上げるのではなく、まず「少ないピン移動で救出する」再挑戦の芯を足す段階。

Studio reported first-time understanding:

- ドラッグする対象は虫ではなくピン。
- ピンの周囲の円が影響範囲。
- 虫が円に入ると進路が曲がる。
- 右端の光る割れ目が出口。
- 入ると `RESCUED` が出て成功。

Studio reported checks:

- `node --check games/specimen-night-shift/game.js` passed.
- `game.json` / `games.json` JSON parse passed.
- Direct launch returned `200 OK`.
- Arcade launch returned `200 OK`.

Studio remaining concerns:

- 実際に出口が割れ目に見えるかは、人間QAで判断が必要。
- ピンの影響を強めた分、簡単すぎる可能性。
- `MOVES` 評価は再挑戦理由の入口だが、まだスコアリングとしては弱め。
- 次に大人向けを強めるなら、予測軌跡か「少ない移動で全救出」ランク表示がよさそう。
